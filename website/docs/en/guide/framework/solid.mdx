# Solid

Learn how to build a Solid application using Rsbuild.

## Create a Solid application

Create a Solid application with [create-rsbuild](/guide/start/quick-start#create-an-rsbuild-application):

import { PackageManagerTabs } from '@theme';

<PackageManagerTabs
  command={{
    npm: 'npm create rsbuild@latest',
    yarn: 'yarn create rsbuild',
    pnpm: 'pnpm create rsbuild@latest',
    bun: 'bun create rsbuild@latest',
  }}
/>

Select `Solid` when prompted to "Select framework", then choose a template.

## Full-stack frameworks

The following full-stack Solid frameworks are built on Rsbuild and reuse Rsbuild's plugin ecosystem.

### TanStack Start

[TanStack Start](https://tanstack.com/start/latest) is a full-stack framework powered by TanStack Router. It provides full-document SSR, streaming, Server Functions, client/server builds, and more.

- [Documentation](https://tanstack.com/start/latest)
- [Example project](https://github.com/rstackjs/rstack-examples/tree/main/rsbuild/tanstack-start-solid)

Create a TanStack Start application with Rsbuild:

<PackageManagerTabs
  command={{
    npm: 'npm create rsbuild@latest my-app -- -t tanstack-start-solid\ncd my-app\nnpm run dev',
    yarn: 'yarn create rsbuild my-app -t tanstack-start-solid\ncd my-app\nyarn dev',
    pnpm: 'pnpm create rsbuild@latest my-app -t tanstack-start-solid\ncd my-app\npnpm dev',
    bun: 'bun create rsbuild@latest my-app --template tanstack-start-solid\ncd my-app\nbun run dev',
  }}
/>

To migrate a TanStack Start project from Vite, see [TanStack Start migration](/guide/migration/tanstack-start).

## Use Solid in an existing project

In an existing Solid v2 project, install the [Solid plugin](https://github.com/rstackjs/rsbuild-plugin-solid#quick-start), then register it in your Rsbuild config:

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core';
import { pluginSolid } from '@rsbuild/plugin-solid';

export default defineConfig({
  plugins: [pluginSolid()],
});
```

If you use Solid v1, see the [Solid v1 setup](https://github.com/rstackjs/rsbuild-plugin-solid#solid-1).
