# Solid

本文介绍如何基于 Rsbuild 构建 Solid 应用。

## 创建 Solid 应用

使用 [create-rsbuild](/guide/start/quick-start#create-an-rsbuild-application) 创建基于 Rsbuild 的 Solid 应用：

import { PackageManagerTabs } from '@theme';

<PackageManagerTabs
  command={{
    npm: 'npm create rsbuild@latest',
    yarn: 'yarn create rsbuild',
    pnpm: 'pnpm create rsbuild@latest',
    bun: 'bun create rsbuild@latest',
  }}
/>

在 `Select framework` 时选择 `Solid`，然后选择所需的模板。

## 全栈框架 \{#full-stack-frameworks}

以下全栈 Solid 框架基于 Rsbuild 构建，并复用 Rsbuild 的插件生态。

### TanStack Start

[TanStack Start](https://tanstack.com/start/latest) 是一个由 TanStack Router 驱动的全栈框架。它提供整页文档 SSR、流式渲染、Server Functions、客户端/服务端构建等能力。

- [文档](https://tanstack.com/start/latest)
- [示例项目](https://github.com/rstackjs/rstack-examples/tree/main/rsbuild/tanstack-start-solid)

通过以下命令创建使用 Rsbuild 的 TanStack Start 应用：

<PackageManagerTabs
  command={{
    npm: 'npm create rsbuild@latest my-app -- -t tanstack-start-solid\ncd my-app\nnpm run dev',
    yarn: 'yarn create rsbuild my-app -t tanstack-start-solid\ncd my-app\nyarn dev',
    pnpm: 'pnpm create rsbuild@latest my-app -t tanstack-start-solid\ncd my-app\npnpm dev',
    bun: 'bun create rsbuild@latest my-app --template tanstack-start-solid\ncd my-app\nbun run dev',
  }}
/>

如果需要将 TanStack Start 项目从 Vite 迁移到 Rsbuild，请参考 [TanStack Start 迁移](/guide/migration/tanstack-start)。

## 在已有项目中使用 Solid

在已有的 Solid v2 项目中，安装 [Solid 插件](https://github.com/rstackjs/rsbuild-plugin-solid#quick-start)，然后在 Rsbuild 配置中注册：

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core';
import { pluginSolid } from '@rsbuild/plugin-solid';

export default defineConfig({
  plugins: [pluginSolid()],
});
```

如果你使用 Solid v1，请参阅 [Solid v1 配置](https://github.com/rstackjs/rsbuild-plugin-solid#solid-1)。
