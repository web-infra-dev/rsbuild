# output.legalComments

- **类型：** `'linked' | 'inline' | 'none'`
- **默认值：** `'linked'`

配置内置 JavaScript 压缩器处理 legal comments 的方式。此选项在启用 [JavaScript 压缩](/config/output/minify) 时生效，不控制 CSS 注释。

## 什么是 legal comments？

Legal comments 包括包含 `@license` 或 `@preserve`，或以 `//!`、`/*!` 开头的 JavaScript 注释。默认情况下，Rsbuild 会将这些注释提取到单独的许可证文件中。

例如 React 的 `LICENSE` 注释：

```js
/**
 * @license React
 * react.production.js
 *
 * Copyright (c) Meta Platforms, Inc. and affiliates.
 *
 * This source code is licensed under the MIT license found in the
 * LICENSE file in the root directory of this source tree.
 */
```

## 可选值

你可以通过 `legalComments` 来配置如何处理 legal comments：

### `linked`

将所有 legal comments 移至 `*.LICENSE.txt` 文件，并通过注释链接到它们。

```js title="rsbuild.config.js"
export default {
  output: {
    legalComments: 'linked',
  },
};
```

`.LICENSE.txt` 文件不会被页面加载，因此它们不会影响页面的性能。

### `inline`

在压缩后的 JavaScript 中保留 legal comments。这可能会导致输出文件的体积变大。

```js title="rsbuild.config.js"
export default {
  output: {
    legalComments: 'inline',
  },
};
```

### `none`

移除所有 legal comments。

```js title="rsbuild.config.js"
export default {
  output: {
    legalComments: 'none',
  },
};
```

:::tip
移除 license 注释可能会违反部分开源软件的许可协议要求。在使用此选项前，请确认你具有移除这些注释的权利。
:::
