# html.crossorigin

- **类型：** `boolean | 'anonymous' | 'use-credentials'`
- **默认值：** `false`

用于设置 `<script>` 和 `<link rel="stylesheet">` 标签的 [crossorigin](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/crossorigin) 属性。

- 当传入 `true` 时，它会被自动设置为 `crossorigin="anonymous"`。
- 当传入 `false` 时，它不会设置 `crossorigin` 属性。

## 示例

```ts title="rsbuild.config.ts"
export default {
  html: {
    crossorigin: 'anonymous',
  },
  output: {
    assetPrefix: 'https://example.com',
  },
};
```

构建后，HTML 中的 `<script>` 标签变为：

```html
<script
  defer
  src="https://example.com/static/js/main.js"
  crossorigin="anonymous"
></script>
```

`<link rel="stylesheet">` 标签变为：

```html
<link
  href="https://example.com/static/css/main.css"
  rel="stylesheet"
  crossorigin="anonymous"
/>
```

:::tip
Rsbuild 会为引用脚本和样式表的标签添加此属性，也包括同源资源。单个标签上已有的 `crossorigin` 属性会保留。
:::

## 可选值

`crossorigin` 可以被设置为以下几个值：

- `anonymous`：请求使用 CORS 头，并将凭据模式设置为 "same-origin"。除非目标是相同的 origin，否则不会通过 cookie、客户端 SSL 证书或 HTTP 身份验证交换用户凭据。
- `use-credentials`：请求使用 CORS 头，凭据模式设置为 "include"，并始终包含用户凭据。
